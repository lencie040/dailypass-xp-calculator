# DailyPass 乗車レベル計算機

[計算機を開く](https://lencie040.github.io/dailypass-xp-calculator/)

## 現在のレベルを取り込む

1. [DailyPass XP Link 1.2.2](https://github.com/lencie040/dailypass-xp-calculator/releases/download/v1.2.2/dailypass-xp-link-1.2.2.jar) を、DailyPass 1.39.0 と Fabric API を入れた Minecraft 1.19.2 クライアントの `mods` に追加します。旧版が入っている場合は差し替えます。
2. Minecraft を再起動し、DailyPass が動いているサーバーに入ります。
3. MinecraftでDailyPassの「乗車レベル」を開き、同じPCで計算機に目標レベルを入力します。Chromeで初めて開くときは「Minecraft と接続」を押して、ローカルネットワークへのアクセスを許可します。数値を更新するときはゲーム内の「乗車レベル」を開き直します。

連携MODはクライアントだけに導入します。DailyPassの乗車レベル画面に届いたデータから自分の総合レベルとXPを読み取り、最後に取得した数値と取得時刻を保持します。ブラウザは同じPCの `127.0.0.1` からその値を読みます。

ブラウザで接続できない場合は、Minecraftの起動中に [ローカル版](http://127.0.0.1:38767/) を開けます。手動入力も使えます。

`100` は `[★]Lv.0`、`599` は `[★★★★★]Lv.99` として指定できます。前回の目標は同じブラウザに保存されます。「乗車プラン」で1回の乗車距離とXP換算を指定すると、精算ごとの切り捨てを含めた回数が分かります。

「保存した目標」は5件まで切り替えられます。「目標リンクをコピー」では目標レベルだけを共有できます。結果の下には途中のレベルごとの累計XPと距離が表示されます。「複数区間のレベル予測」では別々の精算と一括精算を切り替えられます。毎日の乗車回数を決めている場合は、乗車プランで残り日数も計算できます。

今のレベルの必要XPにはサーバーの値を使います。以降のレベルと距離は DailyPass の標準設定で計算します。距離に応じてXPが付く場合の換算は1 kmあたり5 XPで、精算ごとに端数が切り捨てられます。

## MTROPS 路線XPランキング

[路線XPランキング](https://lencie040.github.io/dailypass-xp-calculator/routes.html) は、同じPCで動く MTROPS の `localhost:8765` から運行パターンと駅間データを取得します。連携MOD 1.1.0を入れたクライアントで使えます。総合または鉄道会社を選ぶと、始発から終点まで乗ったときの所要時間・1回のXP・XP/時を比較できます。「種別ごとのベスト」では各種別の1位を表示し、ホワイトリストとブラックリストの両方にある種別は除外します。

会社別の対象距離は、クライアントが読み込んだ DailyPass の会社設定と運賃計算から求めます。駅間の時間が欠けた区間を補う場合は推定と表示します。MTROPSのデータはローカルの連携MODとブラウザで受け渡します。

## MTROPS 折り返しXPランキング

[折り返しXPランキング](https://lencie040.github.io/dailypass-xp-calculator/loops.html) は連携MOD 1.2.0で使えます。今後2時間の駅時刻表と車庫一覧から、同じ車庫に属する上り・下りを含む往復を探します。折り返し駅で復路を待つ時間と、出発駅に戻って次の往路を待つ時間を含め、最大3周の平均でXP/時を比較します。

総合・会社別、駅名、種別で絞り込めます。「同じ車庫の往復のみ」を外すと、別の車庫に属する便も対象にできます。乗り換えに必要な秒数を変更したら「時刻表を更新」を押します。到着時刻を照合できなかった便は所要時間を推定します。

連携MOD 1.2.1の「コスパ重視」は、往復の普通運賃100 CPあたりのXP順で表示します。会社別を選んだ場合も、普通運賃は往復全体で見積もります。運賃表はクライアントが読み込んだDailyPassの設定を使い、定期券や特急・座席料金などは計算の対象外です。

## ビルド

JDK 17 で `./gradlew build` を実行すると、`build/libs/dailypass-xp-link-1.2.2.jar` が生成されます。
