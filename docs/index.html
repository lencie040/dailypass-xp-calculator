距離の計算条件

現在のレベル・獲得XP・次に必要なXPには、連携MODが受け取ったサーバーの値を使います。それより先のレベルは DailyPass 1.39.0 の標準設定が基準です。距離換算は標準で1 kmあたり5 XPです。乗車プランでは、1回の乗車を1回の精算としてXPの端数を切り捨てます。
